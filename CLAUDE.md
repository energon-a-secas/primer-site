# CLAUDE.md: Primer

Primer: learn ML, LLMs, and data insights by building small local projects with tested copy-paste code, then mapping each to the pro stack; 7 tracks across 5 escalating levels, hash-routed hub + track pages, localStorage progress (primer.neorgon.com)

**Live:** primer.neorgon.com · **Port:** 8853

## Run

```bash
make serve
```

Then open http://localhost:8853. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Architecture

| Module | Lines | Owns |
|---|---:|---|
| `js/content.js` | 428 | `LEVELS`, `TRACKS`, `trackById` |
| `js/render.js` | 206 | `render` |
| `js/events.js` | 63 | `bindEvents` |
| `js/state.js` | 56 | `state`, `loadSaved`, `save`, `stepKey`, `isDone` |
| `js/utils.js` | 44 | `$`, `escHtml`, `showToast`, `debounce` |
| `js/app.js` | 14 | none |

Vendored from `packages/neorgon-ui/`: never edit in place, run the sync script instead: `js/neorgon-footer.js`, `js/neorgon-header.js`.

## Data

- `localStorage['primer-progress-v1']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
